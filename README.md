# DIRТLINE — MTB Freeride

A browser-based 2D mountain bike / wheelie game built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — game layout and HUD
- `style.css` — visual design and responsive layout
- `game.js` — bike physics, terrain, trails, wheelies, jumps, crashes, score

## Run it on a Chromebook
1. Download and extract `mtb_wheelie_game.zip`.
2. Open the extracted folder.
3. Open `index.html` in Chrome.
4. Click **START RIDING**.

No terminal or server is required. The game uses a Google font if internet access is available, but the game itself works offline.

## Controls
- **W** — lift the front wheel / hold a wheelie
- **A / D** — balance and lean
- **Space / Up Arrow** — jump
- **Right Arrow** — air steer / pedal forward
- **Down Arrow / S** — brake
- **R** — reset bike
- **P / Esc** — pause

Touch controls appear on small screens. Pick a trail from the right-side panel.
